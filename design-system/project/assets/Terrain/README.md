# Terrain

Fifteen 32 px terrain tiles exported at 96 px, painted in the `terrain-*` tokens (first theme values, which are the same in both themes). Properties — `arcology`, `fabricator`, `skyport`, `dock`, `uplink`, `spire` — are shown unowned, in `terrain-structure` grey; on the battlefield `MapTile` repaints them in the owner's fill with `on-` coloured windows.

Tiles sit edge to edge with no gap. The game draws richer autotiled versions (coastlines, connecting rivers and roads); these are the reference shapes and colours.
