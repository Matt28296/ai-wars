# TurnBanner

The sweep across the screen at the start of each turn: cycle number, nation and commander, in the nation's colours.

**Provide:** `cycle`, `faction`, and the `commander` name.

- Full-width band on the faction fill with on-faction text; the Hollow Choir's obsidian band is rimmed in its red signal.
- On screen for about 1.2 s, sliding in from the left; skipped by any input.
- The big sigil on the right is the band's only decoration.
