# Sigil

A nation's mark: the shape that tells factions apart when colour can't.

**Provide:** `faction` (or `null` for ECHO), `size`, and `tone` for the ground it sits on.

- `tone="ink"` (default) on panels, `fill` on map-shade chips, `on` on a faction fill.
- Every faction colour on screen is paired with its sigil — unit tokens, banners, chips, dialogue names.
- Give it a `title` only when no visible word names the faction.
