# PowerMeter

The commander's power gauge: small diamonds charge Surge, large diamonds charge Overclock.

**Provide:** `value` (stars, fractional), `surge` (stars for Surge), `max` (stars for Overclock).

- Diamonds fill left to right in signal; a partly charged diamond fills partly.
- The label switches from `Charging` to `Surge ready` to `Overclock ready` in signal — the word, not just the glow, tells the player.
