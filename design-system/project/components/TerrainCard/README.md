# TerrainCard

Intel on the tile under the cursor: name, defense stars and capture progress.

**Provide:** `terrain`, `owner` for properties, and `capture` (points remaining) while a property is being taken.

- Sits in a bottom corner of the battlefield and swaps sides when the cursor approaches.
- Defense stars are signal diamonds, empty ones outlined; the number repeats them for screen readers and quick reading.
- Capture fills in `warn` as the points fall from 20 to 0.
