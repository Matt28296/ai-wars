# CommanderPortrait

A commander's face: faction-coloured chamfered frame, sigil watermark, and the portrait or a monogram.

**Provide:** `name`, `faction` (`null` for ECHO), `initials`, an optional `src` for painted art, `size`, and `state` while a power is active.

- 96 px in dialogue and CO select, 48 px in the player HUD. Below 72 px the corner cut shrinks to `chamfer-sm`.
- Painted portraits are 1:1, framed chest-up, facing slightly toward the screen centre.
- The Surge / Overclock band sits on map-shade across the bottom while the power lasts.
